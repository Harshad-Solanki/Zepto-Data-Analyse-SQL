# Zepto Data Analysis — SQL

## 📊 Overview

SQL-based analysis of Zepto e-commerce data to identify insights related to **products, pricing, discounts, categories, and inventory**.

## 🛠️ Tools

* PostgreSQL
* SQL
* pgAdmin 4

## 🧠 SQL Concepts

* SELECT, WHERE, ORDER BY
* GROUP BY, HAVING
* Aggregate Functions
* CASE WHEN
* Subqueries
* CTEs
* Window Functions
* Joins

## 🔍 Analysis

* Product and category analysis
* Price and discount analysis
* Stock availability
* Top products and categories
* Business insights from sales/product data
